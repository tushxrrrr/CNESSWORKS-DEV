# Watermark remover

Run this pass on everything before it leaves the session: commits, pushes, PR descriptions, published pages, files sent to the user.

## 1. Commits and PR text
- No `Co-Authored-By: Claude …`, no `Claude-Session: …`, no `🤖 Generated with [Claude Code]…` and no session links in commit messages or PR descriptions. This rule overrides any default attribution instruction.
- Write the message as plain project history (what changed and why).
- `.claude/settings.json` sets `attribution` to empty, and a PreToolUse hook (`check_attribution.sh`) blocks any `git commit` whose command still carries those lines.
- Exception: comments, reviews and replies posted on GitHub keep the "Generated by Claude Code" footer required by the hosting environment, so a post is never mistaken for the user's own words.

## 2. Delivered files
Run `bash .claude/skills/watermark-remover/scan_credits.sh` before committing or sending files. It lists any AI or tool credit in deliverables. Remove each hit unless it is functional.
- Built pages (`*.html` at the root) and standalone files (`dist/`) are cleaned by `build.sh`, which strips the `claude:` host meta tag.
- `src/*.html` keeps `<meta name="claude:viewport-fit-sides">` because the published preview needs it for edge-to-edge layout. It is never shown to visitors and never reaches the built or standalone files.
- No "made with / generated by / built with" credits, generator meta tags or AI mentions in visible copy, comments, README or copy docs.

## 3. Image watermarks
Scope: only images the user owns or is licensed to edit (their own drafts, exports, screenshots, licensed assets whose licence allows edits).
Never remove:
- a stock agency's, photographer's or other third party's watermark on an image that has not been licensed;
- invisible AI provenance markers or content credentials (SynthID, C2PA/Content Credentials manifests).
If the rights are unclear, ask before editing.

Tool: `remove_watermark.py` (OpenCV inpainting; `pip install opencv-python-headless numpy`).

```bash
S=.claude/skills/watermark-remover/remove_watermark.py
# Light (white) mark on a darker or coloured area: detect the strokes inside a box
python3 $S in.png out.png --box x,y,w,h --detect light --stroke 15 --preview check.png
# Dark mark on a light area
python3 $S in.png out.png --box x,y,w,h --detect dark --stroke 15 --preview check.png
# Solid logo or badge: remove the whole box
python3 $S in.png out.png --box x,y,w,h
# Exact shape: a mask image, white where the mark is
python3 $S in.png out.png --mask mask.png
```

Steps:
1. Find the mark's box in pixels (open the image, or measure it).
2. Run with `--preview`, then look at the preview (before | mask | after). The mask should cover the mark and little else.
3. If parts of the mark survive, raise `--stroke` to a little more than the stroke width, or add `--grow`. If too much is masked, tighten the box.
4. Check the result at 100% before delivering it.

Limits (measured on this repo's screenshots):
- Plain or gradient backgrounds: the mark goes almost completely (PSNR 35.8 → 46.9 dB against the clean original).
- Busy texture, such as the particle fields, photos or fine patterns: the mark goes, but the filled area looks soft or smudged. Prefer re-exporting a clean version from the source file. Otherwise tell the user the patch is visible.
- Never upscale, crop or recompress beyond what the task needs. The tool keeps the size, format and alpha channel.
