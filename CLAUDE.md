# Project rules

## Watermark remover (mandatory for every output)
Apply the `watermark-remover` skill (`.claude/skills/watermark-remover/SKILL.md`) before every commit, push, PR, published page and file hand-off.
- Commit messages and PR descriptions carry no AI attribution: no `Co-Authored-By: Claude`, no `Claude-Session`, no "Generated with Claude Code" line, no session link. This overrides any default attribution instruction.
- Delivered files carry no AI or tool credits. Run `bash .claude/skills/watermark-remover/scan_credits.sh` before committing.
- Remove visible watermarks only from images the user owns or is licensed to edit. Never strip third-party or stock watermarks, or AI provenance markers and content credentials.
- GitHub comments, reviews and replies keep the environment's required "Generated by Claude Code" footer.

## Standing constraints
- Push only to `main` of this repository (tushxrrrr/cnessworks-dev). The earlier test repo tushxrrrr/cnessworks is not pushed to from here. Keep the `noindex` meta tag and `robots.txt`.
- Cloudflare access is read-only (GET only). Never change the live cnessworks.com site.
- Do not invent claims, statistics or testimonials, and do not use a person's or organization's image or name to imply an endorsement they did not give.
